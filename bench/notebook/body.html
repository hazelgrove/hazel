Hazel · Jev study · lab notebook

Can a cheap, fast helper model make Hazel's coding agent faster and cheaper?

Hazel's coding agent is a large LLM that is paid per turn. Jev is a small model that only answers yes/no and multiple-choice questions, quickly and cheaply. Each setup below hands Jev a different part of the work; Agent navigates + edits (original) is Hazel's default agent, unchanged: one LLM that uses Hazel's structured actions to build its own view of the code and make its own edits, with no Jev. Every other setup is compared against it. Every run of every mode on every test is recorded here.
