# Probe-paper docs (staging)

Distilled study-design documentation salvaged from the deleted
`hazel-programs/study/` planning tree, staged here for eventual move to the
probes-paper repo. Process crud (status trackers, build mechanics, CLI
recipes, brainstorm lists) was dropped; design rationale, procedures, and
task documentation were kept.

| File | Source | What it is |
|---|---|---|
| `study-design.md` | `probes-user-study/README.md` | Research questions, IFT framing, probes-vs-print analysis, study design, measures & surveys |
| `debugging-procedure.md` | `probes-user-study/debugging-task-procedure.md` | The M0–M5 milestone scaffolding system for debugging tasks (near-verbatim) |
| `task-design.md` | `writing-tasks-plan.md`, `study-programs.md`, `probes-user-study/writing-tasks-analysis.md` | Error-pattern taxonomy, task categories, bug-design requirements, scaffolding decisions |
| `task-feature-audit.md` | `task-feature-audit.md` | What language features the tasks actually use; tutorial cut/keep implications (near-verbatim) |
| `tutorial-design.md` | `conjoined-tutorial-plan.md` | The conjoined tutorial's organizing principle, multiplicity spine, and design decisions |
| `tasks.md` | per-task READMEs + `tasks-draft/` | Capsule descriptions of the shipped study tasks (and the unshipped families) |

The shipped tutorial itself (slides + embedded task programs) lives in
`hazel-programs/tutorial/*.hzt` and is not duplicated here.
