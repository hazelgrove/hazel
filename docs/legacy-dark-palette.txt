Legacy dark palette (hand-written)
==================================

Verbatim record of the hand-written palette, kept so the derived
scheme can be checked against what a human actually chose.

This is a REFERENCE ARTIFACT, not live code and not a stylesheet.
It lives in docs/ deliberately: src/web/dune copies www as a
source_tree, so a stray .css under style/ ships to the browser and
reads like live-but-broken CSS.

Extracted from src/web/util/ColorConfiguration.re at ecd71c2557.
142 entries, in source order.

The dark scheme this replaces was maintained by hand, independently of
light: same 142 names in the same order, 77 values byte-identical and 65
different. The differences are what a derivation has to reproduce, and
the ones it cannot are the override list.
