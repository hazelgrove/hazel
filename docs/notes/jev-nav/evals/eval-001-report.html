Findings

What broke, and the fix for each

Engine gap

The right answer was not on the menu

Built-ins (map, filter, fold_left) are offered only as bare names, never as typed calls like map(?, ?). Jev escalated correctly 14 times.

Fix: offer every in-scope function whose result type fits the hole as a call with the right number of ? arguments, built-ins included.
Engine gap

Partial builds left holes in the program

Each attempt kept its half-built fun rows -> ?. The program ended worse than it started and evaluated to a stuck term.

Fix: make jev_edit all-or-nothing: if any hole is still open at the end, restore the original and report the open holes to the planner.
Menu noise

Options that can never be right

fun volume -> ?, let cost = ? in ?: binding forms offered once per planner name, including names of existing functions.

Fix: binding forms use only fresh names the planner declares as new; existing names appear only as references or calls.
Planner loop

Neither arm said DONE

Control met the goal early but kept editing until the 24-turn cap; the Jev arm retried the same failing request 14 times.

Fix: stop the run when the goal oracle is satisfied, and tell the planner after 2 identical escalations to change the spec (for example, name map in the call shape).
